hivey improves itself

Agents note what goes wrong. Every Wednesday hivey tells you what it found. You decide what gets fixed.
Checking…

🧠 Is it learning?

Does hivey get better, and do the suggestions get better? One row per month. The logging test proves the notes still arrive, so a quiet week can't pass for a fix.

📬 What should change in how we work

Every Wednesday at the Claude weekly reset, hivey looks for problems that keep coming back and proposes a new rule or habit for the agents, for you or for hivey. Small one-off repairs are handled by the daily check. Nothing changes until you say yes.

🔧 Small fixes

One-off repairs. They don't change how we work, so they aren't up for a vote: the daily check (09:30) tells you once when a new one appears. If the same kind keeps coming back, Wednesday turns it into a change above.

🧩 Problems that keep coming back

A problem has to show up at least 3 times, or in 2 different agents, before it counts as a pattern. One-off errors and harmless misses are left out.

⬢ Token savers

Tools that keep agents from wasting tokens, and whether each one is on. Running agents, failed jobs and spend are on the agent fleet page (hivey menu → agent fleet), so they aren't repeated here.

✅ Is the loop itself working?

Every part of the loop checks itself. Green means it's working; yellow or red tells you what to look at.

Notes written this week

How many notes your agents wrote each day. If the bars stop, the notes have stopped.

🔒 Safety first: what has to exist before hivey can build anything itself

Agents that change themselves can quietly weaken their own checks. So the builder stays locked until all four of these exist.

✨ What changed in AI this week

New releases from Anthropic (Claude), OpenAI and Google, and whether each one matters for hivey.

📈 Did the fixes work?

Each fix you approved gets three numbers: did the problem go down, did anything else break, and what does it cost. A problem going quiet doesn't count as fixed until the numbers show it.

🕳️ A problem the review missed?

Type a problem you hit that no review raised. Next Wednesday hivey looks for it as a known blind spot, and the "Is it learning?" box counts these per month.

🙋 Things you keep doing by hand

Requests you typed again and again on different days. An agent could take these off your plate.

📜 Every step the loop took

The full record, newest first, so you can see each step happened and how it went.

Run it now

You don't have to wait for Wednesday. A full review takes a few minutes and uses one Claude call. The quick check uses no AI and costs nothing.
